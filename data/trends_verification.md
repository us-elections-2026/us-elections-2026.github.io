# `trends.json` 원자료 전수 대조 기록

- **시행일**: 2026-08-12
- **대상**: `data/trends.json` — 20개 주간 포인트(2026-03-23 ~ 2026-08-03), 순지지도 20개 값 + 일반투표 12개 값
- **대조 기준**: 각 주에 대응하는 `issues/<YYYY-MM-DD>.qmd` 주간 브리핑 원문. `trends.json`의 `source` 필드가 이 시리즈의 출처를 "주간 브리핑 종합"으로 명시하므로, 브리핑 기재값을 정본으로 삼는다.
- **방법**: 각 브리핑에서 `순지지|일반투표|제너릭` + 숫자를 포함하는 줄을 전량 추출해 `trends.json` 값과 1:1 대조. 브리핑의 "환경 지표" 표 행을 1차 근거, 본문 서술을 2차 근거로 사용.
- **한계**: Silver Bulletin·RCP 등 **집계기관 원 사이트는 대조하지 않았다**(자동 접근 차단). 따라서 이 기록은 "브리핑과 `trends.json`이 일치하는가"를 검증한 것이며, "브리핑이 집계기관 원값을 옳게 옮겼는가"는 검증 범위 밖이다.

## 4. 남긴 것 (근거가 있으나 성격이 다름 / 아카이브 판단 필요)

**B. 5/25·6/1의 D+8은 집계 평균이 아니라 단일 조사.**
근거가 `Verasight(5/18~19)` 단일 조사다. 시리즈의 다른 주는 Silver Bulletin 등 **집계 평균**이므로 층위가 다르다(프로젝트 원칙: 집계값과 개별 조사는 다른 층). 그래프에서 이 두 주가 D+8로 솟은 것은 여론 변화가 아니라 **출처 층위 변화**일 수 있다. `source` 필드에 이 사실을 명시해 두었고, 값 자체는 브리핑 기재와 일치하므로 임의로 바꾸지 않았다.

**C. 6/15 순지지 −18.7은 6/8과 같은 관측치.**
브리핑이 기준일을 `6/8 (Silver Bulletin)`로 명시하고 "6/15 주 새 집계는 갱신 시 반영"이라 적는다. 즉 신규 관측이 아니라 **이월값**이다. 그래프에서는 두 주가 독립 관측처럼 보인다.

**D. (해소 — §3-④로 이동)** 6/29 브리핑의 구성 수치 `D 49.1 / R 43.5`는 자기모순으로 판정 불가여서 삭제했다.

**E. 5월 저점이 브리핑마다 다르다 — 세 값이 공존. (미해소 — 아카이브 판단 필요)**

`trends.json`은 −20.1(당시 기재값)을 유지했으므로 **사이트가 그리는 계열 자체에는 근거 없는 값이 없다**. 다만 −20.2·−21.2는 `issues/2026-06-08`·`2026-06-15`·`2026-06-22`·`2026-07-20`·`2026-07-27` 5개 브리핑 본문에 사후 서술로 남아 있다. 이들은 **발행된 날짜별 아카이브**라 데이터 파일과 성격이 다르다 — 지우면 그 주에 실제로 무엇이 서술됐는지의 기록이 사라진다. 삭제할지, 각주로 모순을 표시할지, 원 집계 확인 후 정정할지는 편집 정책 결정이 필요해 보류한다.

## 6. 재현 방법

```bash
python3.11 - <<'PY'
import json, os, re
t=json.load(open('data/trends.json'))
def norm(s): return s.replace('−','-').replace('–','-')
for w in t['weeks']:
    f=f"issues/{w['date']}.qmd"
    print("="*80); print(f"WEEK {w['label']}  trends: net={w['trump_net']} gen={w['generic']}")
    if not os.path.exists(f): print("  파일 없음"); continue
    for i,ln in enumerate(open(f,encoding='utf-8').read().split('\n'),1):
        n=norm(ln)
        if re.search(r'(순지지|일반투표|제너릭)', n) and re.search(r'-?\d+\.?\d*', n):
            print(f"  L{i}: {n.strip()[:300]}")
PY
```
