## 4. 발행 (정리본 저장·read-back 확인 후)
**정리본 저장(§1 경로)은 실행 환경과 무관하게 반드시 한다.** 샌드박스에서는 `~`가 실제 홈이 아니므로 `$HOME/mnt/2026_midterm_outlook/senate_daily/site/`(없으면 `$HOME/mnt/_NIS/2026_senate_election/2026_midterm_outlook/senate_daily/site/`)에 저장하고 read-back으로 확인한다. 정리본을 쓰지 않고 끝내는 것은 실패다(2026-09-29~10-02 닷새 결손의 원인).

**발행은 이 작업이 호스트(Mac Studio)에서 직접 한다** (2026-10-03 사용자 결정: GitHub Actions 예약은 꺼져 있고 수동 예비일 뿐이다). 먼저 실행 환경을 확인한다:

```

```

```

```

`$HOME`이 `/sessions/…`이거나 quarto·Rscript가 없으면 발행을 시도하지 말고 정리본 저장까지만 하고 §5의 ⛔ 줄로 보고한다.
